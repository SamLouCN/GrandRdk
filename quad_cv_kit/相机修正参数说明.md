# 独立相机修正工具的当前参数

代码：同目录 `camera_correction.py`。
已导出的参数：同目录 `camera_correction_params.json`。

## 相机参数

| 参数 | 当前值 | 含义和来源 |
|---|---|---|
| model | air_intrinsics_flat_port | 空气内参 + 平面防水窗模型 |
| width / height | 640 / 480 px | 修正处理尺寸；原工程采集整幅 1280×960 后缩小 |
| fx / fy | 318.8 / 318.8 px | 10-06 实跑按接头中心距 0.82 m 反算；对应物理焦距约 3.06 mm |
| cx / cy | 320 / 240 px | 主点取图像中心，未独立标定 |
| distortion | null，按 [0,0,0,0,0] 使用 | 顺序 k1,k2,p1,p2,k3；当前按零假设，不是棋盘格实测结果 |
| n_water | 1.333 | 清水折射率 |
| glass_distance_m | 0.013 m（1.3 cm） | 针孔到玻璃距离，估计值，未实测 |

内参矩阵：

```text
[[318.8,   0, 320],
 [  0, 318.8, 240],
 [  0,     0,   1]]
```

默认值定义在 `camera_correction.py` 的 `default_camera_params()`。
命令行不指定 `--params`、或直接调用 `create_corrector()` 时使用代码默认值。
修改 JSON 后必须指定 `--params camera_correction_params.json`；直接调用时使用
`create_corrector(load_camera_params("camera_correction_params.json"))`。
JSON 不会自动加载，也不会写回原工程配置。

## 深度和画面处理

| 参数 | 当前默认值 | 位置或用法 |
|---|---|---|
| water_depth_m | 1.3 m | camera_height_m()；命令行 --water-depth |
| camera_below_sensor_m | 0.20 m | camera_height_m()；命令行 --camera-below-sensor；原工程记录为 10-03 实测 |
| depth_cm | 无固定默认值 | 当前压力计读数，调用或 --depth-cm 传入；示例的 12 cm 不是强制值 |
| floor_distance_m | 默认不传 | 直接传离底高度，或使用 --floor-distance；不传则忽略玻璃距离带来的视点偏移 |
| rotate_180 | False | 独立工具默认不旋转；尚未转正的装反相机原图使用 --rotate-180 |

高度沿用原工程：max(0.05, 水深 − 压力计深度/100 − 相机低于压力计距离)。
例如 1.3 m 水深、12 cm 压力计读数、0.20 m 安装偏移，得到 0.98 m。
0.05 m 为原工程计算下限，不是测量结果。
原部署设备配置为相机旋转 180°；已转正图像不要再次旋转。
整幅 1280×960 可缩为 640×480；裁剪模式不能通过缩放恢复整幅视场。

当前参数计算的水下视场：水平约 64.21°、竖直约 53.64°、对角约 71.84°；
修正后输出焦距约 474.70 px。这些是模型计算值，不是独立实测。

## 使用

```python
from camera_correction import load_camera_params, create_corrector, camera_height_m, correct_image

camera = load_camera_params("camera_correction_params.json")
corrector = create_corrector(camera)
height = camera_height_m(depth_cm=12, water_depth_m=1.3, camera_below_sensor_m=0.20)
fixed = correct_image(frame, corrector, height)  # 原始装反画面另加 rotate_180=True
```

```bash
python camera_correction.py info --params camera_correction_params.json
python camera_correction.py image --params camera_correction_params.json --input raw.jpg --output fixed.png --depth-cm 12 --water-depth 1.3
```

视频文件修正命令按固定高度处理，输出无音轨 MJPG AVI；高度变化时逐帧传对应高度。
工具仅修正图像，不启动或控制相机硬件。空气棋盘格标定示例中的 9×6 内角点、
25 mm 格长只是示例，须按实际棋盘填写。相机参数改变后，原任务程序需要重新示教。
