# quad_cv_kit —— YOLO 门框内 OpenCV 找红杆解 ψ（独立套件）

水下门（红 PVC 矩形环 70×50cm）的**门内姿态估计**：拿 YOLO 的 `door` bbox，
在框内用 OpenCV 找 4 根红杆 → 拟合四边形 → 给出中心 / 角点 / **ψ（门平面内的偏转角）**。
设计目标：**宁可降级也不给错的 ψ**——观测不完整时按 lvl 阶梯诚实降档，绝不硬编。

来源：RDK S100 水下机器人项目分支②（red_pole_cv），2026-10-06 板端上线。
依赖只有 **numpy + OpenCV（4.x）**，无其他依赖；cv2 4.11 与 4.13 数值一致已双端验证。

## 最小用法

```python
import cv2, quad_cv_det as Q
frame = cv2.imread('f.jpg')            # ★ 必须是干净帧：画面上不能有压在杆上的叠加框
bbox  = (486, 299, 640, 476)           # YOLO door 框 (x1,y1,x2,y2)，全画幅坐标
r = Q.detect(frame, bbox)
# r['lvl']  观测等级（见下）
# r['fields']['psi']          偏转角（0~1 无量纲；乘 AUV_QUAD_FX_PX 变弧度）
# r['fields']['cx'], ['cy']   门中心（全画幅像素）
# r['corners']                4 角点 [[x,y]×4]（lvl4 才有）
# r['why'] / r['diag']        降级原因 / 中间量（各边 support、band_fill、lines…）
```

## lvl 阶梯（观测等级）

| lvl | 含义 | 控制上怎么用 |
|---|---|---|
| 4 | 4 边齐，ψ/中心/角点全有 | 正对伺服闭环 |
| 3 | 只有中心（结构校验没过，ψ 不可信） | 只对中，不转 ψ |
| 2 | ≥1 条线给横向 | 横向修正 |
| 1 | bbox 只有横向位置（门贴边/出画） | 定向转，把门拉回画面 |
| 0 | 无观测 | 保持搜索扫描 |

## 核心公式（★★ 改了就翻车）

- **psi = (ρ−1)/(ρ+1)**，ρ=左右立柱在门深度上的像长比。
  psi>0 = 机头偏右 ⇒ 要**左转**；接线符号 `AUV_QUAD_PSI_SIGN = -1.0`。
- psi 是无量纲小数；要变弧度需 **AUV_QUAD_FX_PX**（焦距像素）标定。
- 门中心 = 四边形**对角线交点**（不是 bbox 中心——bbox 会把出画的杆也框进去）。

## 三道假线判据（为什么不是"找到线就算"）

真实水下（青水、R−G 全画幅恒为负、门右侧常贴边）里假线极多，一道 support 门不够：

1. **edge_trim_px=2**：剔画幅最外 2px——JPEG/采集边行会整行全红；
2. **band_fill ≥ 0.05**：带内密度。真杆 0.13~0.31，断续杂波 p50=0.019，差 15×；
3. **band_run ≥ 0.06**（OR 关系）：最长连续段。保护"只露 13px 的真横杆"不被密度门误杀。

## 已证伪的 ψ 口径（别再试）

- ❌ 立柱可见段比 ⇒ 截断后恒等长，ψ≡0；
- ❌ 上横杆图像倾角 ⇒ 符号翻转；
- ❌ 杆像宽比 ⇒ 符号一致率 0.50（纯抛硬币）。
- 只剩 1~2 条线时**不许**出 ψ，诚实退 lvl=3。

## 关键参数（DEFAULTS，全在 quad_cv_det.py 顶部）

| 键 | 默认 | 说明 |
|---|---|---|
| `red_rel_pct` | 25 | ROI 内百分位基线，做**相对红度**（真水绝对阈值必失效：R−G 恒负） |
| `min_rel` | 22 | 相对红度阈值 |
| `min_band_fill` | 0.05 | 带内密度门（真杆 0.13+） |
| `min_band_fill_edge` | 0.008 | edge 源的放宽档 |
| `min_band_run` | 0.06 | 最长连续段门（OR 通道） |
| `min_support` | 0.50 | 沿线覆盖度门 |
| `edge_trim_px` | 2 | 画幅边行剔除 |
| `roi_pad` | — | bbox 外扩比例（防框紧贴杆把杆切掉） |

## 输入要求（最容易踩的坑）

1. **干净帧**：画面上不能有叠加的检测框/十字线——2px 的框线正好压在杆上，
   要么污染红度要么遮断杆。板端做法：SHM 写原始帧，画框只留显示流。
2. bbox 给 **YOLO 的 door 框**即可，detect() 内部会再外扩 `roi_pad`。
3. 场景里有红色干扰物（红球等）时，把红球 bbox 传进 `ball_boxes=` 参数，会先打孔。
4. 门是 **70×50 非正方形**矩形环；结构校验宽高比按 1.40±0.35 卡（纵向截断时自动跳过）。
