# Task.md —— 2026 水下机器人巡游项目 · 全流程阶段划分

> 依据：《2026-11.1水下机器人巡游规则.pdf》（2026 年度变更：抓取目标物增加红色圆环）
> 用途：作为 `src/to32/move_test/` 任务代码重写的阶段划分基准。
> 阶段接口见 move_test/README.md（Stage 基类：`enter(ctx, now)` / `step(ctx, now, dt) -> cmd | None`）。

---

## 1. 规则规定的任务流程

1. 从出发区释放，自主下潜（**全程任何部位不得露出水面**，露出 = 本次比赛停止）。
2. 自主寻找并**撞击指定颜色球**（红/蓝，抽签决定）——**必须最先完成**，撞球成功后才能做其余任务。
3. 随后按路径方向依次：**过门**（高低交替，按黄色箭头方向穿）→ **抓取目标物** → **投放目标物** → **回到出发区**。
4. 队长上报裁判申请结束，裁判停表。15 分钟未完成则比赛结束。

## 2. 阶段划分：任务阶段 + 运动原语

阶段分两类：

- **任务阶段**（有感知判据）：撞球 / 过门 / 抓取 / 投放 —— 找目标、对准、动作
- **运动原语**（无视觉判据，纯执行）：`Dive` / `Forward` / `Turn` —— 定深、定时直行、定向旋转

原语被任务阶段隔开：任务点之间一律用「Turn → Forward」转移，场地区域间的航向和时长全部参数化，现场按实际布局改 task_config 即可。

## 3. 全流程动作序列（STAGE_TABLE 的最终形态）

```
DIVE(60cm) → FWD(x1) → STRIKE_BALL → TURN(55cm,θ1) → FWD(x2) → GATE_1 → … → GATE_N
→ TURN(θ2) → FWD(x3) → GRAB → FWD(x4) → DROP → TURN(θ3) → FWD(x5,触壁) → DONE
```

| # | 阶段类 | 参数（进 task_config） | 说明 |
|---|---|---|---|
| 1 | `Dive` | target_depth=60cm | 下潜定深至 60cm 工作深度 |
| 2 | `Forward` | duration=x1 s | 定时直行，驶向撞球区 |
| 3 | `StrikeBall` | ball_color | 寻球 → 对准 → 冲撞 |
| 4 | `Turn` | target_yaw=θ1, target_depth=55cm | 定深 55cm 并转向门的方位 |
| 5 | `Forward` | duration=x2 s | 直行接近门 |
| 6 | `Gate` ×N | target_depth(高/矮门), heading | 找门 → 对中 → 穿门（逐门参数化） |
| 7 | `Turn` | target_yaw=θ2 | 旋转朝陈列架方位 |
| 8 | `Forward` | duration=x3 s | 直行接近陈列架 |
| 9 | `Grab` | grab_target(黄球/粉球/红环) | 找目标物 → 近距伺服 → 闭爪 |
| 10 | `Forward` | duration=x4 s | 携球直行到投放区 |
| 11 | `Drop` | drop_depth | 对收集框对准 → 张爪释放 |
| 12 | `Turn` | target_yaw=θ3 | 旋转朝出发区方位 |
| 13 | `Forward` | duration=x5 s, touch_wall=True | 直行直至触壁 → DONE |

> N（门数）与各 θ、x 以现场为准；示意图布局对应 N=4。撞球前的前进 x1 也可换成 Turn（如果出发区朝向不对），序列顺序不变。

## 4. 各阶段规格

### 4.1 运动原语

> **★ 定深口径换算（全文件通用，写代码必守）**
> 本文件所有"定深 XX cm"均指**距池底的高度**，不是水下深度。
> 代码中实际下发的 depth_cm 必须换算：
>
> ```
> depth_cm = 实测水深 − 目标高度 − 机体高度(20cm)
> ```
>
> 例：水深 130cm、撞球工作高度 60cm → depth_cm = 130 − 60 − 20 = **50**。
> 实测水深进 task_config（池深实测后填写），机体高度 20cm 为固定常数。

#### Dive（下潜定深）
- **参数**：`target_depth`（cm）。
- **行为**：heave 推进 + depth_cm 闭环，yaw 保持。
- **完成**：深度连续若干拍稳定在目标带内。
- **兜底**：深度源失效 → 定时下潜 + 固定推力，按时间视为完成。

#### Forward（定时直行）
- **参数**：`duration`（s）、`surge`（速度档）、可选 `target_depth`（行进中保持定深）、`touch_wall`（bool，触壁模式）。
- **行为**：surge 恒定推力 + depth_cm 闭环定深，yaw 锁定当前航向。
- **完成**：计时结束；触壁模式 = 速度遥测骤降/归零提前完成。
- **兜底**：无 —— 定时就是它的完成方式（超时上限即 duration）。

#### Turn（定向旋转）
- **参数**：`target_yaw`（绝对航向 °，相对当前 ±）、可选 `target_depth`（**Turn 兼职变深**：转向同时调深，一个阶段完成"定深 55cm 并转向"）。
- **行为**：yaw_deg 闭环（固件内），surge/sway=0。
- **完成**：航向误差连续若干拍 < 容差。
- **兜底**：遥测无 yaw → 按角速度估算定时旋转，超时接受当前航向。

### 4.2 任务阶段

#### StrikeBall（撞球）
- **目标**：撞上抽签指定颜色的球（红/蓝，半径约 10 cm，悬浮距底约 60 cm）。
- **感知**：VisionIF（球体：颜色 + 圆形 bbox）。
- **流程**：寻球（丢失时按预设航向小幅度扫描）→ 对准（偏差归零）→ 前冲。
- **完成**：冲撞后视为完成（bbox 突变/目标消失 + 定时联合判定）。
- **兜底**：限时未找到 → 扩大扫描；限时未撞上 → 有限重试后继续。
- **红线**：必须最先完成；挂碰/碰线不得分，对准精度不能省。

#### Gate（过门，×N 实例）
- **目标**：按场地箭头方向穿门（70×50 cm 红 PVC 门框；矮门中心距底约 45 cm，高门约 65 cm，交替分布）。
- **感知**：VisionIF（门框 bbox 中心对中 + 门宽推距）+ DepthIF。
- **流程**：找门 → 对中（ex→0）→ 调深至本门 target_depth → 直行穿门。
- **完成**：门 bbox 占宽先超阈值后收缩/消失（已穿出）+ 定时。
- **兜底**：丢门 → 定时直行硬穿；判据失效 → 门宽阈值 + 定时。
- **红线**：按行进方向穿，反穿不得分；同门多次穿只计一次 → 不回头。

#### Grab（抓取）
- **目标**：在陈列架（约 0.5×0.5 m，目标距底 20–40 cm）抓取抽签指定目标物。2026 起有两种：
  - 高尔夫球（黄 / 粉，抽签定颜色）
  - **红色圆环**（环径约 120 mm，气动管外径 10 mm，微负浮力）
- **感知**：VisionIF（红环与门/收集框同色，靠尺寸与位置区分）。
- **流程**：找目标物 → 近距伺服 → 机械手闭合。
- **完成**：夹持确认（机械手状态）或定时。
- **兜底**：限时未抓到 → 有限重试后进入 Drop（带不带由机械手状态定）。

#### Drop（投放）
- **目标**：把目标物投进收集框（约 30×40 cm，红框，距底 20–60 cm）。
- **感知**：VisionIF（红框，靠形状尺寸与圆环/门区分）+ DepthIF。
- **流程**：对框伺服 → 定深对准 → 张爪释放。
- **完成**：释放动作完成（定时）。
- **兜底**：找不到框 → 在估计位置释放。

## 5. 贯穿全程的规则红线（写代码时的硬约束）

1. 任何阶段都不得让机器人露出水面 → 所有 target_depth 必须留水面安全余量。
2. 撞球完成前不得执行过门/抓取/投放（STAGE_TABLE 顺序已保证）。
3. 所有动作必须有传感依据，随机运动完成的任务不得分 → 任务阶段判据失效走"定时 + 安全路径"。
4. 无缆自主：比赛开始后无电缆、无无线遥控。
5. **定深口径**：一切定深目标按"距池底高度"给出，下发前必须换算
   `depth_cm = 实测水深 − 目标高度 − 机体高度(20cm)`（见 §4.1 公式框）。

## 6. 代码落点

- 原语类（Dive/Forward/Turn）与任务类（StrikeBall/Gate/Grab/Drop）都写在 `src/to32/move_test/mission.py`
- 完整动作序列排进 `task_config.STAGE_TABLE`，即 §3 那张表的直接翻译：
  ```python
  STAGE_TABLE = [
      Dive(cfg), Forward(cfg, x1), StrikeBall(cfg),
      Turn(cfg, yaw=θ1, depth=55), Forward(cfg, x2),
      Gate(cfg, n=1), …, Gate(cfg, n=N),
      Turn(cfg, yaw=θ2), Forward(cfg, x3), Grab(cfg),
      Forward(cfg, x4), Drop(cfg),
      Turn(cfg, yaw=θ3), Forward(cfg, x5, touch_wall=True),
  ]
  ```
  （实例化形式实现时定，此处仅示意参数归属）
- 任务参数（θ1..θ3、x1..x5、球色、门数、各门深度、抓取对象）全部进 `task_config.py`
- 观测只走 `obs.VisionIF` / `obs.DepthIF`；`obs.CANON` 需补圆环（ring）标签
- 机械手动作（闭爪/张爪）在 Grab/Drop 的 step 内发下行帧或经 ctx 扩展
