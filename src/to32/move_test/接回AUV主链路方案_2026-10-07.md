# AUV 模式接回主链路方案 v1 —— 先方案后动手

状态：**已落地并验证（2026-10-07）** · 更新：2026-10-07（落地记录与实测修正见文末 §5）
目标（用户口径）：**关闭测试模式**时切 AUV = 依次自动完成所有阶段任务；**开启测试模式**时切 AUV = 只测选定的一个/几个阶段。现状是关测试模式时 AUV 位注册 `AuvModeStub`（占位壳，静止不动），正式 `AuvMode`（move_test/mode_auv.py）自 2026-10-04 摘除后未注册。

## 0. 目标行为矩阵（本方案的核心，一张表说清）

| TEST_MODE_ENABLED | mode=1 时 AUV 位坐谁 | 驱动表 | 行为 |
|---|---|---|---|
| **False（关）** | 正式 `AuvMode`（move_test/mode_auv.py） | `task_config.STAGE_TABLE` | 依次自动跑完全部阶段 → stop 一拍收尾 → 静默 |
| **True（开）** | `TestMode`（test_runner.py，**现状不动**） | `test_config.TEST_TABLE` | 只跑选定的阶段组合；随时切回 ROV；退出自动停推 |
| 文件缺失 / 加载失败 | `AuvModeStub`（现有占位壳） | —— | **静止** + journal 打印原因，绝不静默跑任务 |

同一模式位、注册时 if/else 互斥，开关只在 dispatcher 启动时读一次——**结构上保证两者不可能同时生效**。

## 1. 改动清单（3 个文件，约 35 行）

### 1.1 mode_dispatcher.py（核心，~18 行）

- 新增 `_load_auv_mode()`，完全仿照 `_load_test_mode()` 的防御式写法：
  - 把 `move_test/` 插进 `sys.path`（mode_auv.py 自带注入，双保险无害）；
  - `from mode_auv import AuvMode`；**任何异常 → print 进 journal + 返回 None**（中位机启动不被拖垮，回退占位壳）；
  - 已核无遮蔽风险：`src/to32/` 顶层没有同名 `mode_auv.py`（2026-10-04 摘除时已删，Glob 确认只剩 move_test 一份）。
- `_register_modes()` 的 else 分支改为：
  ```python
  else:
      cls = self._load_auv_mode() or AuvModeStub   # 正式优先，加载失败回退占位壳
      auv = cls(self)
      auv.id = auv_id
      self.modes[auv.id] = auv
  ```
- ⚠ **一个必须堵的语义洞**：现在 `_load_test_mode()` 在 test_config.py **加载失败**时也返回 None。接回后 None 会落到正式 AuvMode——等于"开关开着、以为在测试模式，却静默跑了正式任务"。要区分三态：
  - test_config import **失败**（开关状态未知）→ **AuvModeStub 静止** + journal 报错（保守：宁停勿跑）；
  - import 成功且 `TEST_MODE_ENABLED=False` → 正式 AuvMode；
  - import 成功且 `True` → TestMode（test_runner 再挂也回退 stub）。
  实现上给 `_load_test_mode()` 加一个失败标记（或拆出 `_test_mode_state()` 返回 off/on/broken），注册处据此三选一。

### 1.2 move_test/mode_auv.py（安全补齐，~6 行，唯一动 move_test 的地方）

- `on_exit` 补一拍停推帧：非 estop 闩锁时下发 `S.frame_motion(..., stick_stop=1)`——与 `TestMode.on_exit` 同语义。否则中途切 ROV/IDLE 时，最后一条 0x09 推力指令"悬空"在固件里（TestMode 已堵这个洞，正式壳必须同样堵上）。
- 其余一概不动（Mission 构建、estop 红线排在一切下发之前、yaw mirror、日志节流均现状）。

## 2. 行为推演（关测试模式 + 切 mode=1，接回后）

1. `on_enter`：发 0x04=0x05（下位机进 AUV 语义）→ 建 `Mission(TC)`，日志「N 个阶段」；
2. 依次跑各 Stage：每段完成（或 SearchBall 见球提前退出）→ 同拍切下一段；段内异常 → Mission 捕获 → ABORT stop 收尾（现状机制）；
3. 全部完成：发一拍 `stop=1`（"任务结束，停推"）→ 之后 0x09 静默；
4. 中途随时切 ROV 手动接管（on_exit 先补一拍停推，ROV 立即接管杆位）；重新切回 AUV = `on_enter` 重建 Mission **从头跑**；
5. 急停：estop 闩锁期间一个字节不发（tick 里排在一切下发之前，现状不变）；
6. ⚠ **无兜底口径提醒**：Turn/Dive 段判据失效（$TEL 无 yaw / depth_kalman 未起）会**停在那一段持续下发**，永不完成——下水前确认融合深度与遥测正常。
