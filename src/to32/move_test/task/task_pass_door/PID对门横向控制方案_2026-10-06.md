## 一、现有数据链路（已在跑，无需改）

```
front.py (YOLO) ──写──> /dev/shm/momo_det_front.json
                          │ center=[cx,cy], bbox, 画面 640×480, 瞄准点(320,240)
vision_if.poll('front','gate') ──> dx = cx-320 (像素差)
                          │        ex = dx/320 ∈ [-1,1] (半宽归一化)
viskf_if.read() ─────────> e_x (按门框宽归一化, 无量纲、与距离无关)
                          │        de_x (横向偏差速度, 滤波器自带)
                          │        sig_x / trust (可信度)
mission._servo_gate_yaw() ──> 目前只有 P: rate = 25°/s × e_x, 积分进绝对目标航向
mode_auv.tick() (~20Hz) ──> 组 0x09: Target_Yaw(度×100) + Sidesway_Thrust(sway×127)
```

## 二、误差量选择

三个口径，**主回路用 viskf 的 e_x**：

| 口径 | 优点 | 缺点 |
|---|---|---|
| 原始 dx 像素 | 直观 | 远近增益不一致 |
| ex（半宽归一化） | 与分辨率无关 | 仍随距离变 |
| **viskf e_x（门宽归一化）** | 无量纲、与距离无关，远近同一套增益；自带 de_x（D 项现成） | 依赖 viskf（挂了要回退） |

D 项直接用滤波器给的 de_x，不要自己数值差分（放大噪声）。

## 三、PID 结构（增量式 → 积分进绝对目标航向）

固件 yaw 通道是闭环航向环（吃 Target_Yaw 绝对角），sway 是开环推力。

**航向主回路：**

```
e    = e_x                        (本拍横向偏差)
ê    = de_x                       (滤波器给的偏差速度)
rate = Kp·e + Ki·Σ(e·dt) + Kd·ê   (期望艏向角速度, °/s)
target_yaw = wrap180(target_yaw + rate·dt)   ← 积进绝对目标角, 0x09 下发
```

即现有 `_servo_gate_yaw` 骨架，补 Ki/Kd 和抗饱和。

**必配保护项：**
1. 死区：|e| < e_dead 输出 0（e_x 口径约 0.04~0.05，对应原 15px）
2. 输出限幅：|rate| ≤ rate_max（固件满偏 60°/s，先限 15~20°/s）
3. 积分分离/抗饱和：|e| > e_big（如 0.3）不积分；target_yaw 到限位冻结积分
4. trust 门控：viskf trust=False 或门丢失超 N 拍 → target_yaw 保持不动

**横移 sway（副回路，分段策略，避免双执行器打架）：**
- 远/中距离（门框未贴边）：只用 yaw 对中；
- 近距离（门框占画面大半、yaw 修正扰动大）：切 sway 微调
  sway = clip(Kp_s·e_x + Kd_s·ê, ±0.3)，同时 yaw 增量归零。

## 四、横移距离的物理换算（仅作参考量）

```
f_px = (W/2) / tan(FOV_h/2)        (水平焦距, 像素)
X_off = dx · Z / f_px              (横向偏移, 米)
Z = f_px · W_gate_real / w_bbox    (由已知门宽反推距离)
```

约束：sway 通道无位置环（推力→速度，无里程计），横移"距离"只能当
开环动作的参考（固定时长/固定推力），不能距离闭环。
工程结论：**闭环就闭环在 e_x 上，e_x→0 等价于横移到位**。

## 五、参数初值与整定顺序

- Kp ≈ 25（°/s；e_x=0.1 时给 2~3°/s，与现 AUV_KP_YAW_DPS 同量纲）
- Kd ≈ 8~12（viskf 已滤波，可以给大点压超调）
- Ki ≈ 2~5，最后加，只消稳态残差（如相机装偏的恒偏 0.03），配积分限幅
- 顺序：P（能对中可能震荡）→ 加 D 压超调 → 小 Ki 消残差；
  用 logs/front.log 的 e_x 曲线判断震荡。
