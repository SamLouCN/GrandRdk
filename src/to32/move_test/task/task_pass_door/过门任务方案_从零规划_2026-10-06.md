> 目标：AUV 前视 YOLO 找门 → 自动对准（yaw + sway 双环）→ **对准后关掉视觉，陀螺仪盲跑穿门**。
> 未实施，未写任何代码。
>
> v4 修订（按用户意见）：
> ① 对准只在对准阶段。对准完成后**整块关掉视觉算法**，锁死目标航向，靠固件航向环（陀螺仪）盲跑前进
>    ——过门时图像变化太复杂，既然已经对准，就没理由再用视觉；
> ② 急停逻辑从本方案中**整体删除**（由现有机制负责，任务不额外处理）；
> ③ 删野值剔除，改为**对 e 做滤波**（互补 or 卡尔曼，选型另行研判，接口留成可插拔）；
> ④ 状态机定稿为三态：**等门 → 对准 → 关视觉盲跑**。

## 一、双执行器对准（v3 结论不变）

只调 yaw 对准的是"画面中心"不是"门的法线"，门斜时是窄门；运动抖动还会出现"居中但歪"。
所以对准阶段 yaw 与 sway **同时闭环在同一个误差上**：

```
e_f = filter(e_raw)                    # e_raw = (cx − 320)/320，滤波后参与控制
Δψ   = KP_YAW·e_f − KD_YAW·ω           # ω = 遥测陀螺仪 z 轴角速度
sway = KP_SWAY·e_f                     # 小死区
ψ_target = wrap180(ψ_lock + Δψ)
```

- ψ_lock：进对准态时取当前实际航向；误差进入死区期间用当前实际航向持续刷新（重锚定）；
- 单目测不出门的真实斜角，"正对"靠双环压死 e 来逼近；严格正对判定后期再说。

## 二、三态流程（定稿）

```
① 等门   没门: 原地保持(surge=0, sway=0, 航向保持)
            │ 连续 2 拍见门
            ▼
② 对准   yaw+sway 双环闭环, surge=0
            │ |e_f| < E_DEAD 连续保持 T_ALIGN 秒
            ▼ 锁死 ψ_target = 当前值, 【整块关掉视觉对准算法】
③ 盲跑   surge = GATE_SURGE, ψ_target 不再更新(锁死), sway = 0
            │ 航向由固件航向环闭环保持——环内反馈就是陀螺仪, 任务侧零参与
            │ 出口: 暂按盲跑时长 T_BLIND 到时停, 过门判定后接(留桩)
            ▼
          停 surge=0（本期到此为止）
```

**盲跑态要点**：
- 视觉链路（读 det JSON、PID、锚定）整块停用，不再消费任何图像数据；
- ψ_target 冻结为对准完成瞬间的值，0x09 每拍照发同一个目标角（或按协议变化才发），
  保持靠固件航向环，任务侧不碰；
- 丢帧规则只属于等门/对准两态（冻结上一帧位置）；盲跑态没有视觉，不存在丢帧；
- 通用异常（没门超时、盲跑超时）→ 停 surge、上报，不另设 FAIL 状态机分支。

## 三、e 的滤波（v4 补充：viskf 输入输出已核实 + 陀螺仪进卡尔曼）

### 3.1 现有 viskf 的输入 / 输出（按源码 `viskf/camera_kalman/src/viskf.py` 核实）

**输入（两个文件，各带新鲜度降级）**：

| 输入 | 来源 | 内容 | 用途 |
|---|---|---|---|
| `/dev/shm/momo_det_front.json` | front.py（已在写） | dets: label/score/bbox/center，帧号去重 + mtime 新鲜度（0.5s 超时） | 选最优 door 框 → 观测 |
| `/dev/shm/momo_telemetry.json` | 中位机 shm_sink | pitch、roll（rad），新鲜度四档 ok/hold/degraded/none | 观测端姿态反旋转补偿（超时降级当水平） |

**注意：当前 viskf 只吃 pitch/roll 角度，没有吃陀螺仪角速度。**

**输出（`/dev/shm/momo_viskf.json`，原子写 tmp+replace）**：

| 字段组 | 内容 |
|---|---|
| 横向通道 | `e_x`（门宽归一化横向偏差）、`de_x`（偏差速度）、`sig_x` |
| 升降/前向 | `el, del, sig_el`、`s_n, ds_n, sig_s` |
| 可信度 | `trust`（外推防护位）、`gate_visible`、`age`、clip 贴边标志 |
| 姿态状态 | `att{pitch,roll}`、`att_ok / att_hold / att_degraded` |

滤波器本体：三个相互独立的 2 维 CV 线性卡尔曼（Joseph 形式），非线性全部前置在 `measure()`。
首测两坑（出框口径跳变、自由外推失控）已修复，e_x 通道实测高频降噪 2.5~3.6x、无明显滞后。

### 3.2 陀螺仪能不能放进卡尔曼？——能，而且这正是评测报告指出的改进方向

**放法：作为预测步的控制输入 u**（不是第二个观测）。原理：门静止时，画面里门的运动
100% 来自机器人自身运动——横移和转动。机头转动 ω（rad/s）使整个画面平移 ≈ f_px·ω（像素），
除以门框宽 w_px 就是 e_x 的变化量：

```
预测步:  e_x⁻ = e_x + (de_x + u_ω)·dt
         u_ω  = (f_px / w_px) · ω · GYRO_SIGN      # ω 来自遥测, w_px 是当帧门框宽
         de_x⁻ = de_x                               # 匀速假设不变
```

价值：现在滤波器的 Q（信运动）与 R（信观测）严格互斥——Q 大跟得快但降噪差，反之亦然。
加了 u 之后"机器人自己动"的部分被预测步直接解释掉，Q 只需要兜底横移和噪声，
**降噪与跟随不再互斥**（这正是 09-24 评测报告写明的结论）。

**放进去的前提（缺一不可）**：
1. `f_px` 必须先标定——现在用的 1108 是占位值，这个因子不准则 u_ω 整体不准（P0）；
2. 遥测 JSON 要含角速度字段 ω_z——需确认 `link_stm32.parse_telemetry` 是否已输出，没有就在中位机侧补；
3. 符号对齐：`GYRO_SIGN` 与 measure() 的镜像/口径统一，现场标定一次写死；
4. 贴边帧 w_px 不可信 → 该拍 u_ω 沿用上一次的门框宽（防因子跳变）。

**对滤波选型研判的修订**：
- 首选：**viskf + 陀螺仪 u 项**——现成工程、坑已修过、结构验证过，加 u 是它自己报告里指明的下一步；
- 备选：互补滤波（实现最简单，但吃不到 u 的好处，滞后-降噪照样互斥）；
- 卡尔曼收益最大的前提是上面 4 条前提能落实；f_px 标不了的话 viskf 退化为"纯滤波"模式（u=0），与互补滤波同级别。

### 3.3 方案侧接口（不变 + 一条依赖）

- 接口仍是 `e_f = filter.update(e_raw, dt)` 可插拔，`GATE_EF_TYPE = none | viskf | complementary`；
- 若选 viskf：**e_f 直接用它的 e_x（门宽归一化口径）**，不再自己算 (cx−320)/320，
  PID 增益物理含义随口径走（KP_YAW 的"每单位 e 对应几度"要按新口径重标）；
- `de_x` 顺带可得，若后续想加速度前馈有现成量。

### 3.4 【决策存档 2026-10-06】滤波路线定稿（防上下文丢失）

> **结论：现在的 viskf 继续用；陀螺仪 u 项（§3.2）作为二期增强，写在这里防止遗忘。**

- 一期（写算法 + 实机对准）：对准环的 e_f 直接消费 **viskf 现有输出 `momo_viskf.json` 的 `e_x`**
  （门宽归一化口径），配置 `GATE_EF_TYPE='viskf'`；viskf 没在跑或 trust=False 时按丢帧冻结处理。
  本地仿真/回放时可切 `GATE_EF_TYPE='none'` 用直通口径。
- 二期（真机标定后）：给 viskf 预测步加陀螺仪控制输入
  `u_ω = (f_px / w_px) · ω · GYRO_SIGN`（§3.2），打破 Q/R 互斥。
  **启用前提**：① `VISKF_FOCAL_PX` 真机标定（现在 1108 是占位）；② 遥测 JSON 补 ω_z 字段
  （确认 `link_stm32.parse_telemetry` 是否输出）；③ `GYRO_SIGN` 与 viskf 内部口径对齐；
  ④ 贴边帧 w_px 冻结沿用。这 4 条没齐之前 u_ω 不上，viskf 维持现状跑。
- 这个决策的背景：viskf 三通道 CV 线性 KF 结构已验证（坑已修、不发散），
  差的是标定和姿态链，不是结构问题——所以先上算法闭环，滤波增强并行准备。

## 四、参数表（进 config）

```python
# ---- 对准环 ----
GATE_KP_YAW    = 30.0
GATE_KD_YAW    = 12.0
GATE_KP_SWAY   = 0.8
GATE_SWAY_DEAD = 0.03
GATE_E_DEAD    = 0.04
GATE_T_ALIGN   = 2.0
GATE_KI        = 0.0      # 默认不给, 路径保留
GATE_I_MAX     = 1.0
GATE_PSI_MAX   = 0        # 输出限幅默认关
# ---- 盲跑 ----
GATE_SURGE     = 0.35
GATE_T_BLIND   = 8.0      # 盲跑时长 s, 过门判定接入后替换
# ---- 滤波器(选型后补参数) ----
GATE_EF_TYPE   = 'none'   # none=直通 | viskf | complementary
GATE_FOCAL_PX  = 1108     # 占位值, 用 viskf+u 前必须真机标定
# ---- 符号 ----
GATE_E_SIGN    = +1
GATE_GYRO_SIGN = +1
GATE_WAIT_TIMEOUT = 30.0  # 一直没门 → 停并上报
```

整定顺序：KP_YAW → KD_YAW → KP_SWAY → E_DEAD/T_ALIGN → 滤波器选型接入 → 盲跑时长按实测门距定。
