## 一、状态机（GateMission 3 态 → 5 态：找门/逼近/对准/盲冲/DONE）

> 2026-10-08 用户修正：**第一步不是等门，是找门**——过门阶段启动时门不在视野里，
> 被动保持没意义。S0 改为主动扫描：悬停 + yaw ±30° 来回扫。

```
S0 SCAN  找门（新增，替换原"等门"）
   动作: 悬停（surge=0 sway=0 定深 hold_depth）+ yaw 扫描：
         ψ_center = 进态时实际航向（锁存，同撞球/PickRing 惯例）
         扫描半幅角**渐进增幅**（2026-10-08 用户口径: 不要一下子加到 30°）:
         第一段只扫 ±GATE_SCAN_AMP_START(10°)，每折返一次 +GATE_SCAN_AMP_STEP(5°)
         → ±10→±15→±20→…→封顶 GATE_SCAN_AMP(30°)；
         每到一端驻留 GATE_SCAN_DWELL（等 YOLO 确认，~10 个检测帧）再折返；
         门在正前方时由折返过渡段自然覆盖。
   出口: 连续 GATE_LOCK_FRAMES 帧见门 → ψ_lock=当前实际航向 → S1
   超时: GATE_WAIT_TIMEOUT（30s）一直没门 → 告警并继续扫（不自行处置，v4 精神）
           │
           ▼
S1 APPROACH  远 · 仅 YOLO
   控制: surge=GATE_SURGE_FAR 前进逼近
         ψ_target = wrap180(ψ_lock + GatePid(e_f))      # 现有 e 环原样复用
         sway = KP_SWAY·e_f                              # v4 双环沿用，远距横移效果弱属正常
   出口: w_ratio ≥ GATE_W_FAR 且 CV_READY(lvl≥3 连续 GATE_CV_LOCK_FRAMES 帧) → S2
   滞回: w_ratio < GATE_W_FAR−0.08 不回退（防临界抖动）
   丢帧: 冻结 + surge=0（沿用通用规则）；丢门 > GATE_LOST_WAIT → 回 S0 重扫（扫心=当前航向）
           ▼
S2 FINE  近 · CV 主导（原 ALIGN 扩展）
   输入: psi_f  ← lvl=4 时更新，KF1D 平滑，GATE_PSI_HOLD_S 内沿用（消费侧保证连续性）
         e_f    ← e 源升级：lvl≥2 用四角对角线交点 q_ex（消 ψ/2·w 偏差），lvl<2 退 bbox ex
   控制: Δψ = GatePid(e_f) + GATE_PSI_SIGN·KP_PSI·psi_f    # e 环与 psi 环并联
         sway = KP_SWAY·e_f；surge=0
   出口=回正判定（全部满足持续 T_ALIGN；★2026-10-08 仿真修正: surge=0 不会接近,
        删除原 ③ w_ratio≥W_BLIND 门槛——自相矛盾, 盲冲距离由 T_BLIND 覆盖）：
     ① |psi_f| ≤ GATE_PSI_DEAD                # 正对（无量纲，免标定）
     ② |e_f| ≤ GATE_E_DEAD                    # 居中（沿用 0.04）
     ③ psi 新鲜：距上次 lvl=4 ≤ GATE_PSI_HOLD_S
     ④ 矩形确认位（只做门禁不做控制量）：par_h ≤ GATE_RECT_PAR_MAX
        （par_h/orth_err 来自此包 quad_geom，符号不可控，只当"没骗线"的旁证）
   丢门 > GATE_LOST_WAIT → 回 S0 重扫
           ▼
S3 BLIND  回正盲冲（v4 口径不变）：ψ_target 冻结，视觉整块停，surge=GATE_SURGE
   出口: T_BLIND 到时停（二期换 out_frac 出画判据，见 §五）
   ▼
   DONE  surge=0 保持航向（本期终点，不变）
```

- 找门/逼近/对准共用同一套丢帧冻结规则（ψ_target/sway 保持、surge=0、LOST_WAIT 内无缝续）；
  区别只在超时去向：S1/S2 超时回 S0 重扫（原"回 WAIT"改为重扫，门丢了就该找）。
- **三相位与 CV 残缺高发区天然错开**（见 §二）：S1 时门远、杆太细，本来就不该用 CV；
  S2 只在 lvl=4 稳定的中距工作；S3 干脆关视觉。

## 三、Issue2「无标定，不知道 3 个距离」——控制量全部改免标定口径

> **用户口径确认（2026-10-08）：不知道距离也行——每个轴都是「像素偏差 → 移动量」的比例闭环，
> 偏差越小移动量越小，偏差归零即对准。全程不需要任何米制标定。**

逐轴映射（全部是像素/归一化量，偏差→移动量）：

| 轴 | 像素偏差量 | 移动量（输出） | 增益 / 死区 |
|----|-----------|---------------|------------|
| 横向 | e_f（门中心 vs 画面中心，归一化） | Δψ（转）+ sway（平移） | KP_YAW=30°/unit、KP_SWAY=0.8；死区 0.04 / 0.03 |
| 正对 | psi_f（左右竖边像长比） | Δψ 叠加项 | KP_PSI=25°/unit 起调；死区 0.04 |
| 垂直 | e_y（交点中心纵向） | 定深微调 / 仅确认 | 主用定深通道，视觉死区确认 |
| 前向 | w_ratio（屏占比） | surge | 不做比例：S1 恒推力逼近，到阈值转 S2 后 surge=0（等效"越近移动量越小"） |

比例闭环三条守则（都是现成机制，不是新增工作）：
1. **死区必须有**——否则永远在微调抖动（E_DEAD / SWAY_DEAD / PSI_DEAD 已备）；
2. **阻尼必须有**——GatePid 的 KD 项（陀螺仪 ω）就是干这个的；psi 环增益从小起调，振荡再加大；
3. **偏差量必须零位正确、对距离单调**——psi 与 e 都满足（kit 原注释口径），这正是选它们当偏差量的原因。

**角度：3 个里视觉只需要管 1 个，且免标定。**
- yaw 正对 = psi（竖边像长比，闭式 (ρ−1)/(ρ+1)，>0=机头偏右应左转），**不需要任何标定**；
- pitch → 定深通道管（深度计已有）；roll → IMU 管。视觉侧 tilt/par_v 符号依赖门在光轴上下方，
  **永不做控制量**（quad_geom 原注释口径），只进日志。

**距离：3 个里 0 个需要米制标定——全部改成闭环归零或占比阈值。**
- 横向 x：不反算距离，伺服 e→0 归零即对中（死区归一化口径，KP 已有）；
- 垂直 y：定深按赛前量好的门中心水深设定（任务参数，非视觉标定）；视觉只留 e_y 死区做确认；
- 前向 z：**不进控制量**，只用于相位切换阈值 → 用免标定代理量 w_ratio（bbox 宽/画幅宽）和
  quad 宽占比（z∝1/w，单调够用）。切换阈值（GATE_W_FAR / GATE_W_BLIND）是**调参不是标定**，
  池试一次定下来写死。

**二期可选（真要米制 z 才做）**：
- fx 两点法标定（约 5 分钟）：已知距离 d 拍门，量四边形宽 w_px ⇒ fx = w_px·d/0.70（门宽 0.70m）。
  有了 fx：z = fx·0.70/w_proj、psi 可换算成真角度 psi_deg；
- kit 的 `gate_guidance.py` 已实现四点平面 PnP（0.70×0.50m 门）可出 3 角 3 距，但 README 自认
  **姿态有明显双解、参数未经实测、不输出运动控制**——只作参考件，不直接上车。

## 六、参数增量（gate_config.py）

```python
# ---- 找门扫描（S0, 渐进增幅）----
GATE_SCAN_AMP     = 30.0   # 扫描半幅角上限（°）
GATE_SCAN_AMP_START = 10.0 # 起始半幅角（°），第一段只扫 ±10°
GATE_SCAN_AMP_STEP  = 5.0  # 每次折返增量（°），封顶 AMP
GATE_SCAN_DWELL   = 1.0    # 每端驻留时长 s（~10 个检测帧，够 LOCK_FRAMES 确认）
# ---- 三相位切换 ----
GATE_SURGE_FAR    = 0.30   # S1 逼近推力
GATE_W_FAR        = 0.35   # S1→S2：屏占比阈值（起调值）
GATE_W_BLIND      = 0.55   # 回正盲冲的距离门（起调值）
GATE_CV_LOCK_FRAMES = 3    # CV_READY：lvl≥3 连续帧数（滞回防抖）
# ---- CV 通道 ----
GATE_CV_ENABLE    = True
GATE_CV_PERIOD_S  = 0.12   # 节流（ARM 解码+detect 30~60ms/次）
GATE_PSI_KP       = 25.0   # °/unit psi（psi=0.1 → 2.5°）
GATE_PSI_DEAD     = 0.04   # 正对死区（无量纲；fx 标定后可换 psi_deg≤3°）
GATE_PSI_HOLD_S   = 1.0    # psi 沿用窗（lvl<4 时保连续）
GATE_PSI_SIGN     = -1     # psi>0=机头偏右应左转；上车一次标定（同撞球流程）
GATE_RECT_PAR_MAX = 8.0    # 矩形确认位 par_h 门限（°，只做门禁）
GATE_CV_FX_PX     = 637.6  # 占位（640×480 的 318.8 按 1280×720 中心裁切换算），仅 psi_deg/二期用
```
