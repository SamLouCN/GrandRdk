# DYP-L08 超声波高度计多路读取 — /userdata/USART

板端 RDK S100 + CH348 扩展串口读取**电应普 DYP-L08-V3.0 系列**超声波水下高度计（Modbus-RTU），
**支持 A–E 五口各挂一台，每口完全独立**：缺几个口照常运行，某口异常不影响其它口。
规格书：`DYP-RD-产品规格书(DYP-L08&L08B-V3.0)-260713-A0.pdf`（深圳市电应普科技有限公司，V1.3）。

## 一、硬件接线

| CH348 侧 | 高度计侧 | 说明 |
|---|---|---|
| 对应口 RX | 模组 TX/A | UART 受控型号接 TTL；RS485 型号经收发器接 A 线 |
| 对应口 TX | 模组 RX/B | B 线同理 |
| 5V / GND | VCC / GND | **5V DC 供电，超 4.75~5.25V 可能永久损坏** |

板端设备节点（CH348，沁恒 1a86:55d9, ch9344 驱动，枚举 8 路）：

| 物理口 | A | B | C | D | E | F | G | H |
|---|---|---|---|---|---|---|---|---|
| 设备节点 | /dev/ttyCH9344USB0 | USB1 | USB2 | USB3 | USB4 | USB5 | USB6 | USB7 |

**本脚本默认使用 A–E（USB0–USB4），`--channels` 可任意组合。**

## 二、通讯参数与协议（规格书 3.3 节）

- 模式：**Modbus-RTU**，CRC-16/MODBUS
- 波特率：默认 **115200**，8 数据位 / 1 停止位 / 无校验（寄存器 0x0201 可改）
- 从机地址：默认 **0x01**（寄存器 0x0200 可改，0x01~0xFE）
- 读功能码 0x03 / 写功能码 0x06；寄存器数据**高字节在前**；读取间隔须大于响应时间

### 常用寄存器（单位：mm）

| 寄存器 | 功能 | 响应时间 | 备注 |
|---|---|---|---|
| 0x0100 | 处理值（算法滤波后距离） | ≈135ms | 只读，数据平稳 |
| **0x0101** | **实时值（本脚本默认）** | ≈20ms | 只读，实时性最好 |
| 0x0123/24/25 | 回波 1/2/3 距离 | ≈20ms | 只读 |
| 0x0126/27/28 | 回波 1/2/3 幅值(mV) | ≈20ms | 只读 |
| 0x0200 | 从机地址 | - | 读写，默认 0x01 |
| 0x0201 | 波特率 | - | 读写，0x09=115200 |
| 0x0208 | 角度等级 1~4 | - | 读写，默认 4（等级越大越灵敏） |
| 0x021F | 测距量程(mm) | - | 读写，默认 10000，范围 300~15000 |
| 0x023C | 休眠（写 1 立即休眠） | - | 只写（仅 UART 受控输出有效） |

> 注：规格书 3.1 节另有 **UART 受控输出模式**（TTL RX 低脉冲触发 → TX 输出
> `FF DataH DataL SUM` 4 字节）。本脚本走 **Modbus 通道**，两套输出方式不混用。

## 三、多路读取脚本 read_altimeter.py

每口 = 一条独立线程 + 独立串口句柄 + 独立统计。**缺口容错**：
- 某口打开失败（节点不存在）：仅该通道跳过，其余照常；
- 某口连续 10 次无响应：打印提示后降为 2s 低频探测，**不影响其它通道**，
  接上高度计后自动恢复正常节奏；
- 输出统一 **mm 原生单位**（不换算 m/cm）。

```bash
cd /userdata/USART

# 默认：同时读 A–E 五口（各自 0.2s 间隔，只插了部分口也能跑）
python3 read_altimeter.py

# 只读某一个口（如当前只有 B 口接了设备）
python3 read_altimeter.py --channels B

# 任意组合
python3 read_altimeter.py --channels A,C,E

# 改读 0x0100 处理值（滤波；响应 ~135ms，间隔建议 ≥0.3s）
python3 read_altimeter.py --reg 0x0100 --interval 0.3

# 所有口的从机地址统一改为 0x02
python3 read_altimeter.py --addr 0x02
```

参数：`--channels`（默认 A,B,C,D,E）、`--baud`（115200）、`--addr`（0x01）、
`--reg`（0x0101）、`--interval`（0.2s）。Ctrl-C 结束并打印各通道汇总表。

## 四、量程与注意事项（规格书 1.4 / 七）

- L08：盲区 ≤5cm，平面物体量程 5~800cm，探测角度 15±5°（L08B：盲区 ≤8cm，量程 8~800cm，25±5°）
- 精度常温 ±(1 + S×1%) cm（S 为实际距离）；供电 **5V DC**（4.75~5.25V），峰值电流 40mA，超压可能永久损坏
- 超声波受环境干扰：气泡、浑浊、大流速涡流、不同介质混合物可能误测/无法测量
- 上电工作时间 <600ms；工作温度 0~50℃；安装时保持模组垂直被测平面
- 模组 5 秒无 RX 触发进入休眠、唤醒多 ~12ms 是 **UART 受控模式**特性；Modbus 查询模式按本脚本 0.2s 节奏不会休眠

## 五、实测记录（2026-09-03）

- 请求帧 `01 03 01 01 00 01 D4 36`（与规格书 3.3.4 例 2 完全一致），应答 `01 03 02 02 29 78 FA`，CRC 通过
- B 口实跑：**0x0229 = 553 mm**；连续采样 551~553mm，均值 ~552.6mm（静态场景）
- 五口并发验证：仅 B 接设备 → B 正常读数，A/C/D/E 判"未接设备"降频，互不影响，Ctrl-C 汇总正确
